# Цифровой сервис поступления — Академия гражданской защиты имени М. Габдуллина

Объединённый сайт для абитуриентов **Академии гражданской защиты имени М. Габдуллина МЧС Республики Казахстан** (г. Кокшетау).

Собран из трёх проектов:

| Источник | Что взято |
|---|---|
| **agz-site** | Дизайн сайта (шапка, подвал, цвета, шрифты, анимации), главная, «Правила приёма», «Информация о поступлении», «Программы», «ДЧС по регионам», ИИ-ассистент, сервер ИИ |
| **талапкер.html** | Кабинет абитуриента: регистрация и вход по ИИН + код + ЭЦП, документы личного дела, проверка сертификата ЕНТ, отправка заявки, уведомления, этапы отбора, анкета, обращения, RU/KZ |
| **талапкер-демо.html** | Кнопка «Демо-вход» (тестовый абитуриент без ЭЦП) |
| **комиссия.html** | Панель приёмной комиссии: входящие, сводка, база заявок с фильтрами, доработка, этапы отбора, обращения, аналитика, карточка личного дела |

Кабинет и панель комиссии оформлены в дизайне сайта Академии и работают с **одной общей базой**.

## Открыть сайт

Откройте `index.html` в браузере — всё работает без сервера.

- Кабинет абитуриента: `cabinet.html` (демо: `cabinet.html#demo`)
- Панель комиссии: `commission.html` — служебный вход `komissiya` / `4455`

Изменения, сделанные в кабинете, сразу видны в панели комиссии (в том же браузере — даже в соседней вкладке) и наоборот.

## Мобильная версия и приложение

Сайт адаптирован под телефоны и планшеты (проверено на ширинах 320, 360, 390, 768 px и на компьютере):
меню-«бургер», таблицы превращаются в карточки, вкладки кабинета и комиссии листаются пальцем,
ИИ-ассистент и карточка личного дела открываются на весь экран, телефоны кликабельны, учтены вырезы экрана iPhone.

Если сайт размещён по **https** (или открыт через `server/` на localhost), его можно установить как приложение:
- Android / Chrome — пункт «📲 Установить приложение» в меню сайта;
- iPhone / Safari — «Поделиться» → «На экран „Домой“».

Установленное приложение открывается без адресной строки и работает без интернета (страницы, сохранённые
сервис-воркером `sw.js`). **После любых правок файлов сайта увеличьте версию `CACHE` в `sw.js`** (например, `agz-v2`),
иначе у пользователей останется старая копия. При открытии сайта двойным щелчком по файлу установка недоступна —
это ограничение браузеров.

Файлы: `manifest.webmanifest`, `sw.js`, `img/icon-192.png`, `img/icon-512.png`, `img/icon-maskable-512.png`, `img/apple-touch-icon.png`.

## Общая база Supabase и хостинг Vercel

Без настройки данные хранятся в браузере (видны только на этом устройстве).
Чтобы абитуриенты и комиссия работали с одной базой с любых устройств:

**Supabase (база и файлы)**
1. Создайте проект на supabase.com.
2. SQL Editor → New query → вставьте весь файл `supabase/schema.sql` → Run.
   Создаются таблицы `applicants`, `log`, `files`, функция `agz_patch`, бакет `documents`, включается Realtime.
3. Settings → API Keys: скопируйте **Project URL** и **Publishable key** (`sb_publishable_…`)
   в `js/config.js`. Secret / service_role key в сайт не вставлять никогда.

**Vercel (хостинг)**
1. Загрузите папку сайта в репозиторий GitHub (папку `server` загружать не нужно).
2. vercel.com → Add New → Project → Import этого репозитория → Framework Preset: **Other** → Deploy.
3. После каждого изменения в репозитории Vercel обновляет сайт сам.
   Меняя файлы сайта, увеличьте версию `CACHE` в `sw.js`.

`vercel.json` — заголовки для сервис-воркера и манифеста; `.vercelignore` — что не публиковать.

### Безопасность

Сейчас база работает в **режиме прототипа**: вход абитуриента (ИИН + код + ЭЦП) и пароль комиссии
проверяются в браузере, а правила доступа в `schema.sql` разрешают чтение и запись всем,
кто знает адрес сайта. Для демонстрации этого достаточно, но **реальные персональные данные
(ИИН, телефоны, сканы документов) загружать нельзя**, пока не сделано:
вход через Supabase Auth (отдельные учётные записи для абитуриентов и сотрудников комиссии)
и правила RLS «абитуриент видит только своё дело, комиссия — все».
## Бэкенд с «живым» ИИ (необязательно)

В папке `server/` — бэкенд на Claude (Anthropic API), который умеет сверять информацию с официальным сайтом `agz.edu.kz`.

```bash
cd server
npm install
copy .env.example .env    # вписать ANTHROPIC_API_KEY
npm start                 # http://localhost:3000
```

Без ключа сайт всё равно работает — ИИ-ассистент переключается в офлайн-режим.
